X-Band 3-Way Wilkinson Power Divider
Designed using Cadence AWR Microwave Office
Overview

This repository contains the complete design, simulation, and layout of an X-Band (9–15 GHz) three-way Power Divider implemented using microstrip transmission lines in Cadence AWR Microwave Office.

The design focuses on

Equal power division
Good impedance matching
High isolation
Compact microstrip implementation
EM validated layout
Features
Frequency Range: 9–15 GHz
Equal three-way power split
50 Ω input/output ports
Full-wave EM simulation
Optimized microstrip layout
Smith Chart validation
Return Loss optimization
Isolation analysis
